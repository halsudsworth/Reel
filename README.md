# R.E.E.L.

**Remove Everything Except Line.** Immersive fishing for World of Warcraft: Forever. The interface fades, the water stays.

For WoW Forever only. Install from CurseForge or Wago, or drop the `Reel` folder into `Interface\AddOns`. In game: `/reel`.
